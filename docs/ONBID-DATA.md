원본/실행정보/CSV/품질보고서는 Git에서 제외되는 `backend/data/onbid/run-20261104-annual/`에 저장했다. 서비스 키는 저장소에서 제외된 `.env.onbid.local`의 `ONBID_SERVICE_KEY`에서 읽는다. 키나 요청 전체 URL은 출력하지 않는다.

## 재현

프로젝트 루트에서 표준 Python 3.11 이상으로 실행한다. 추가 패키지는 필요 없다.

```bash
python3 backend/scripts/onbid_data.py collect \
  --start 2025-11-04 --end 2026-11-03 \
  --output backend/data/onbid/NEW_UNIQUE_RUN --max-calls 100
python3 backend/scripts/onbid_data.py preprocess \
  --run backend/data/onbid/NEW_UNIQUE_RUN
python3 backend/scripts/test_onbid_data.py
```

`--output`은 새 폴더여야 한다. 기존 수집을 덮어쓰지 않는다. 원본은 월별 응답 JSON, manifest는 키를 제외한 조회 조건·실제 호출 수·페이지별 행 수·수집시각·SHA-256을 기록한다. 성공한 모든 페이지의 행 수가 서버 totalCount와 일치해야 수집 완료로 표시한다. 전처리는 완료된 수집과 원본 체크섬을 확인한다.

## 전처리 계약

- `normalized_all.csv`: 중복 처리 후 모든 자동차 범주의 정규화 결과.
- `passenger_clean.csv`: `승용차`, `SUV`, `경차`라는 명시된 원천 범주 중 필수 필드가 유효한 결과. 실제 데이터에는 경차가 별도 범주로 없었으며 모닝 등은 승용차로 분류되어 있었다.
- `excluded.csv`: 범주/필수 값 문제 또는 중복으로 제외한 행과 사유.
- `quality_report.json`, `quality_report.md`: 표본 수, 범주, 결측률, 제외 사유, 모델별·월별 수, 검토 플래그.

금액은 원, 거리는 km, 배기량은 cc, 개찰일시는 한국 시간이다. 연식은 모델 연도이므로 `age_years_approx`는 근사 차령이다. 제조사/연료/배기량 결측을 보존하고 별도 플래그를 둔다. 모델명은 유니코드·공백만 정리하며 세대/트림을 추측하지 않는다.

이벤트 키는 물건관리번호+공매조건번호+개찰일시다. 같은 이벤트의 주요 값이 같으면 한 행만 남기고, 값이 충돌하면 해당 이벤트의 모든 행을 제외한다. 물건관리번호는 `vehicle_group_id`로 보존한다.

원본 물건명에 폐차·고철·부품용, 점검용, 2대 이상·일괄매각이 명시된 행은 개별 운행 차량 가격모델에서 제외한다. `외 N건`은 금액의 품목 단위가 불명확해 별도 확인 전까지 제외한다. 묶음 낙찰가를 차량 수로 나누거나 대표 차량 한 대 가격으로 쓰지 않는다. `폐차불가`, `1대 매각`은 이 규칙으로 제외하지 않는다. 차량번호를 포함할 수 있는 원본 제목은 정제 CSV로 옮기지 않고 제외 사유만 남긴다.

주행거리 0 또는 100만 km 초과는 원천 검증 전까지 모델 입력에서 보류한다. 10만 원 미만 또는 3억 원 초과 가격과 계획 차령 1~12년 밖의 행은 `review_flags`만 남긴다. 가격이 크거나 작다는 이유만으로 행을 제거하는 타깃 절단은 하지 않는다.

초기 형식 정리 결과는 2,256행이었으나 원본 점검에서 141대 폐차 묶음 낙찰가 301,770,000원과 온비드 점검용 차량 15,000원이 발견됐다. 동일한 원천 단위·목적 규칙을 전체에 적용해 59행을 추가 격리한 최종 결과가 2,197행이다. 이는 모델 평가 점수를 보고 기준을 조정한 것이 아니라 관측 단위 오류를 수정한 것이다. 모든 원본 응답은 그대로 보존했다.

## 모델/Colab 사용

`onbid_data.py`는 독립적으로 Colab에 업로드해 import할 수 있다. 이미 수집한 `manifest.json`과 `raw/`를 업로드하면 키 없이 전처리를 다시 실행할 수 있다.

```python
from pathlib import Path
from onbid_data import preprocess
report = preprocess(Path("data"))
```

모델 후보 입력은 `make`, `model`, `model_year`, `age_years_approx`, `odometer_km`, `fuel`, `displacement_cc`, `vehicle_category`다. 전체 데이터에서 결측 대체나 인코더를 학습하지 않았다. 시간순으로 분리하고 `vehicle_group_id`가 훈련·검증·테스트에 겹치지 않도록 해야 한다. 식별자와 사후 낙찰가율/입찰자 수 등은 모델 입력에서 제외한다.

목표 `price_krw`는 **공매 낙찰가격**이다. 소매 호가, 딜러 매입견적, 매매 완료가격과 같지 않다. 반복 공매의 관측이 있더라도 같은 차량의 장기 감가 경로가 검증된 것은 아니다. 사고·정비·트림 정보도 이번 데이터로 확보하지 않았다.
