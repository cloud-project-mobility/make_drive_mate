# DriveMate 인수 메모

작성 기준: **2026-11-04, ECS 서비스 생성 전**. 로컬 실행과 기존 EC2 환경의 공개 HTTPS 검증을 완료했고, 사용자의 요청에 따라 ECS Fargate로 전환을 준비하고 있다. ECS 클러스터·ECR은 생성됐지만 **ECS 애플리케이션 서비스와 최종 운영 URL은 아직 확인되지 않았다**. 원본 Word·PowerPoint 파일은 이번 작업에서 수정하지 않았다.

## 전달된 기능

사용자가 차량 조건을 입력하면 온비드 공매 낙찰 자료로 학습한 모델이 현재 조건의 참고 가격을 계산한다. 차령·예상 주행거리·입력 유지비를 바꿔 보유 조건을 비교하고, 데이터가 부족하면 가격 제시를 유보한다. 이는 소비자 중고차 시세나 확정 매입견적, 실제 미래 시장가격 예측이 아니다.

화면은 실제 공매 모델, 데이터 분석 집계, 기존 오프라인 합성 계산, 프로젝트 문서 근거 검색을 구분한다. GPT는 검증된 가격·사례 설명 또는 문서 출처를 선택하며 가격 자체를 생성하지 않는다.

## 숫자를 보고하는 방법

| 가격 모델 평가                        |  표본 |        MAE | 함께 표시할 정보                                    |
| ------------------------------------- | ----: | ---------: | --------------------------------------------------- |
| 전체 최종 시험                        | 341건 | 236.15만원 | 모든 시험 자료에 대한 결과                          |
| 사전에 정한 제공 조건에 맞는 부분집합 | 262건 | 134.74만원 | 제공률 76.83%, 79건 유보. 전체 결과를 대신하지 않음 |

정제 2,197행 중 시간 경계를 넘는 53개 차량 그룹·122행을 제외한 분할은 훈련 839, 검증 559, 구간 보정 336, 시험 341행이다. 차종·세대·사고·정비·트림 정보의 한계와 공매 표본 편향을 함께 설명한다. 조건부 MAE를 전체 정확도나 소비자 매입가격 정확도로 바꾸어 쓰지 않는다.

가격 유보는 미학습 모델·제조사 조합 또는 핵심 수치의 훈련 범위 이탈에 적용한다. 같은 모델의 훈련 표본이 10건 미만인 경우는 경고이며, 그 조건 하나만으로 자동 유보하지 않는다. 범위 안에 있다는 사실이 모든 차량 조합의 근거가 충분하다는 뜻은 아니다.

문서 검색은 개발자가 작성한 작은 확인용 질문 10개에서 Recall@1 0.70, Recall@3 0.90, Recall@6 0.90, MRR@6 0.7667이었다. 독립적인 일반 성능 시험이 아니다. 문서 밖 질문 3개는 실제 LLM 선택에서 3/3 보류했지만, 단순 유사도 게이트만으로는 3개 모두 통과했다. 따라서 “환각 0%”, “정확도 100%”, “문서 밖 질문 완벽 차단”으로 쓰지 않는다.

## 현재 실행과 AWS 상태

핵심 제품 작업 중 실제 ML 결과와 매도 목표·최소 보유기간을 함께 적용하는 추천 흐름, 실제 미래 시장가격 검증, 보유비용 근거 확보는 남아 있다. 기존 오프라인 합성 계산을 실제 ML 추천 통합으로 보고하지 않는다. 신규 차량 관련 RAG 자료는 아직 기존 6문서·83청크 서비스 색인으로 확대 반영하지 않았으며, 팀원 모바일 검증과 원본 PoC·중간보고서·PPT 수정도 별도 남은 작업이다.

로컬 기본 웹은 `http://127.0.0.1:8081`, Spring은 `http://127.0.0.1:18085`다. 로컬 기본 계정 저장소는 H2이며 파일 기반 문서 검색에는 `DRIVEMATE_RAG_BACKEND=local`을 명시한다. 운영 기본값인 `pgvector`는 기존 AWS RDS·HTTPS 경로에서 확인했다. 요청이 실패했다고 자동으로 local로 바꾸지 않는다. 실행·팀 분담 절차는 [TEAM-HANDOFF.md](TEAM-HANDOFF.md)를 따른다.

`backend/data/local-run/verification.json`에서 로그인 200, 예약 이메일 일반 가입 403(`email_reserved`), 실제 ML+GPT 요청 200(7.77초), local RAG+GPT 요청 200·`answered`(6.71초), 분석 집계 200을 확인했다. 시간은 각 1회 관측이며 지연시간 보장이나 성능 벤치마크가 아니다. RAG 검색 방식은 `bm25+local-cosine-rrf`로 기록됐다.

이전 실패 스택의 정리와 최종 암호화 백업 보존은 과거 이력이다. 이후 새 EC2·RDS와 ECS 기반 자원을 만들었으므로 “현재 서버/DB 없음”으로 표현하지 않는다. ECS 전환이 확인되기 전에는 기준 EC2 환경을 지우지 않는다. 자세한 상태는 [AWS 실행 기록](../infra/aws/DEPLOYMENT-STATUS.md)을 따른다.

일반 API task는 DB master secret·초기 소유자 비밀번호·bootstrap token을 받지 않으며 스키마 자동 초기화도 끈다. 다만 기존 bootstrap의 `drivemate_app` 역할은 현재 schema/table owner이므로 DB 권한을 DML 전용으로 낮춘 상태는 아니다. 위치 중계는 메모리 기반 단일 replica이며 task 교체 시 사용자가 다시 연결해야 한다.

유료 기능은 **UTC 날짜 기준 서버 전체 요청 20회/일** 한도를 공유한다. 문서 검색 1회는 임베딩 호출을 포함하고 GPT 옵션은 추가 호출을 할 수 있으므로 “OpenAI HTTP 호출이 정확히 20회 이내”와 같은 뜻이 아니다. 실패·미설정 요청도 슬롯을 소비할 수 있다. 이 요청 한도와 예산 알림은 AWS 월 지출의 자동 차단 보장이 아니다.

공개 저장소는 사용자가 지정한 [cloud-project-mobility/make_drive_mate](https://github.com/cloud-project-mobility/make_drive_mate)다. 최초 통합 업로드는 [`8b8eea7484ebe8cf8f2dde10ab0f6737a1d5aa21`](https://github.com/cloud-project-mobility/make_drive_mate/commit/8b8eea7484ebe8cf8f2dde10ab0f6737a1d5aa21)이며 이후 변경과 CI 결과는 [Actions 기록](https://github.com/cloud-project-mobility/make_drive_mate/actions)을 따른다. 기존 `FE-test`는 로컬 작업본의 기반으로 구분한다. 소스·테스트·개인정보 없는 기술 문서와 코드 전용 노트북만 공개하며 원본 Office 문서·데이터·모델·RAG 본문/색인·키·계정 설정은 제외한다. CI 성공과 ECS 배포 완료·CD 활성화는 서로 다른 상태다.

## 검증·보존 사항

- 기록된 최신 로컬 Spring 검사는 **57개, 실패 0건**이다. 실제 WebSocket·Origin·메시지 순서 검사를 포함하며 운영 배포 성공 횟수가 아니다.
- 프런트 타입·린트와 단위 98개, 위치 브라우저 12개가 통과했다. 합성 위치로 명시적 시작·중지, 권한 오류·오프라인·화면 이탈·30초 만료·기존 GPS 회귀를 확인했다.
- 컨테이너 준비 로직은 합성 ZIP/S3 자료로 10개 검사를 통과했다. 실제 로컬 이미지에서 UID 10001·읽기 전용 루트·볼륨 쓰기·Spring/Nginx·합성 WS 중계/격리/중지를 확인했다. 실제 Fargate 기동 검증을 대신하지 않는다.
- RAG의 추출·출처·가림·오류·환경변수 처리 단위 테스트는 9개, CI 배포 어댑터 테스트는 7개다. 이는 실제 RDS 검색 또는 GitHub 원격 Actions 실행 성공 횟수가 아니다.
- 06:55 UTC의 이전 차량 카탈로그 통합본에서는 TypeScript·ESLint·90개 검사와 웹 export 986개 모듈을 확인했다. 이후 위치 UI와 카카오 지도 설정을 포함한 최종 웹을 다시 export했다. 카카오 JavaScript 공개 키가 포함되는 빌드와 서버용 비밀 키가 제외되는 조건을 구분한다. 이전 파일 수·용량을 최신 빌드 지표로 사용하지 않는다.
