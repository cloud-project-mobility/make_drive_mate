# 실제 공식 Sample 응답 자료

2026-11-25 실행에서는 공식 누적거리 Sample에서 HTTP 403 오류 JSON을 받았습니다. 거리 데이터를 담은 성공 응답은 0건입니다. 이 디렉터리에 실제 성공 fixture는 없습니다. [비식별 진단](../../docs/evidence/sample-odometer-20261125.json)
output/sample-settings-windows.json의 HTTP 404는 설정 조회 실패이며 차량 Sample 응답이 아닙니다.
fixtures/mock_responses는 직접 만든 합성 응답입니다. 공식 문서의 예시도 실제 수신 응답으로 취급하지 않습니다.
향후 응답을 공유할 때는 허용 조건 확인·비밀정보 제거 후 수신 출처/시각과 마스킹·가공 내역을 별도로 기록해야 합니다.
