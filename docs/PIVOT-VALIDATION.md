# 가치·매도 시점 전환 검증

검증일: 2026-11-02 (Asia/Seoul). API 키 없이 합성 데이터와 직접 입력한 견적으로 동작하는 프런트 목업을 검증했다. 학습된 시세 모델의 정확도를 평가한 기록은 아니다.

접근성 검사는 최초에 시나리오 카드의 `aria-label`이 화면에 보이는 가격·비용을 포함하지 않는 문제를 발견했다. 짧은 덮어쓰기 이름을 제거하여 화면 텍스트 전체를 읽도록 수정했고, 해당 E2E는 안정된 testID를 사용하도록 변경했다. 한 차례 병렬 빌드 중 브라우저 컨텍스트가 종료되어 검사를 끝내지 못했으나, 빌드 종료 후 전체 검사를 다시 실행하여 위 최종 결과를 얻었다.

## 확인한 동작

기본 시나리오의 가치와 비용을 독립 계산해 테스트·PPT·설계서와 비교했다. 최소 보유기간/비용 한도/목표가를 바꾸면 후보가 변하며 모든 조건을 만족하는 후보가 없으면 유보한다. 가격 하한이 목표가를 밑돌거나 하한 기준 비용이 한도를 넘으면 조건부로 안내한다. 이력이 미확인인 경우는 시점을 제안하지 않는다. 견적은 날짜와 함께 입력하며 기준일 이전 30일 이내만 허용한다. 현재 분석 기준일은 2026-11-02로 고정되어 있다.

원래 등록 차량의 주행거리와 백업 구조를 분석 폼이 변경하지 않는지, 재시작시 분석값이 초기화되는지 확인했다. 기존 정비·주행·일정·백업 기능의 브라우저 통합 검사를 유지했다.

## 남아 있는 범위

실차 시세 수집, 학습, 시간 외 성능 평가, 시장의 미래가격 검증, 소비자 매입가 검증, 가치 분석용 서버 API 및 AWS 운영은 후속 계획이다. 가격 범위는 임의 가정폭이고 통계적 신뢰구간이 아니다. 이번 변경은 기존 의존성 버전을 변경하지 않았으며, `npm audit`에는 기존 트리의 26개 항목(낮음 2·보통 22·높음 2)이 보고되었다. 주요 SDK를 임의로 강등하는 자동 수정은 수행하지 않았다.
