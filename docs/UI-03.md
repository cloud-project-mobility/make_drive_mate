# UI 03: 계정·차량 등록과 일상 관리

기준: 2026-11-05 로컬 변경. **새 UI 03의 AWS 배포와 새 Android APK 빌드는 아직 완료하지 않았습니다.** 현재 운영 API revision 4와 이전 APK의 검증 이력을 이번 화면·상담 기능의 운영 검증으로 대신하지 않습니다.

## 처음 시작하기

1. **계정 만들기**를 선택해 이메일·비밀번호로 실제 DriveMate 회원가입을 합니다. 기존 계정은 **이미 계정이 있어요**로 로그인합니다.
2. **내 차 등록**에서 차량 이름, 제조사·모델·연식, 누적 주행거리, 구동 방식을 확인합니다. 차종 목록에서 고르면 사진을 연결하고 연식을 별도로 입력합니다. 내연기관·하이브리드·전기차는 구동 방식이며 연료 종류나 배기량을 뜻하지 않습니다.
3. **등록하고 시작하기**를 누르면 계정 차량 API 저장을 확인한 뒤 기기 목록에 추가하고 홈으로 이동합니다. 서버 저장 실패는 오류로 표시하며, 재시도 전 기기에 성공한 것처럼 추가하지 않습니다.

회원가입과 차량 등록은 별도 단계입니다. 온보딩 중에는 관리 메뉴와 하단 탭을 숨깁니다. 차량 등록 중 페이지를 다시 열어 로그인 세션이 사라지면 재로그인을 요청하며, 계정 저장을 조용히 기기 저장으로 바꾸지 않습니다.

**예시 차량으로 둘러보기**와 **내 차량으로 시작하기**는 작은 보조 동작으로 유지합니다. 전자는 합성 차량·기록을, 후자는 빈 기기 기록을 사용합니다. 예시 차량은 사용자의 실제 차량 정보가 아닙니다.

## 화면별 동선

작은 화면에는 하단 **홈 / AI 상담 / 이동 계획 / 내 차** 4개 탭을, 넓은 화면에는 상단 탐색을 표시합니다. 계정은 상단 사용자 아이콘으로 들어가며 기존 `/settings` 주소를 유지합니다.

| 화면      | 기본 내용                                                            | 필요할 때 여는 기능                                                              |
| --------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 홈        | 선택 차량, 기존 공매 분석 결과 또는 미분석 안내, 다음 이동·점검 항목 | 질문을 AI 상담으로 전달, 가격 비교, 이동·점검 상세                               |
| AI 상담   | 차량 맥락, 질문과 답변, 근거 및 유보 상태                            | 차량 조건·유지비 입력, 공매 비교 근거·출처, 전송 정보                            |
| 이동 계획 | 예정·완료 기록과 도착·출발 시각                                      | 새 계획, 일정으로 계획, 사용자 시작 주행 기록, 웹 실시간 위치                    |
| 내 차     | 차량 선택, 차량·주행·정비 기록                                       | 최대 3대 등록, 계정에 저장한 차량 불러오기                                       |
| 내 계정   | 로그인 또는 현재 계정·로그아웃                                       | 계정 보안, 외부 서비스 연결, 계정별 서버 백업, 운전·알림, 기기 데이터, 참고 자료 |

로그아웃한 기존 기기 사용자는 **기기 설정 보기**를 눌러 관리 메뉴를 펼칩니다. 처음부터 백업·초기화 버튼을 나열하지 않습니다. 기기 데이터 초기화·복원은 확인 절차를 거치며 진행 중인 주행을 덮어쓰지 않습니다. 연결된 알림 해제에 실패하면 데이터 삭제·대체를 멈춥니다.

## 가격 분석과 일반 상담

| 사용자 동작                    | 서버 경로                            | 계산과 비용                                                                                                                                             |
| ------------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 입력 확인하고 공매 가격 분석   | `POST /api/v1/valuation/simulations` | 고정된 가격 모델을 실행합니다. 이 동작은 OpenAI를 호출하지 않으며 서버 실행비는 별도입니다.                                                             |
| AI에게 보내기                  | `POST /api/v1/assistant/query`       | 자유 질문을 GPT로 처리합니다. 확인된 분석 입력이 있으면 서버가 ML을 다시 계산해 근거로 사용합니다. OpenAI 호출 비용과 서버의 공용 AI 한도가 적용됩니다. |
| 참고 자료의 프로젝트 문서 검색 | `POST /api/v1/knowledge/query`       | 별도 허용 계정 기능입니다. 검색만 요청해도 질문 임베딩 비용이 발생합니다.                                                                               |

AI 상담에는 질문·직전 질문, 안전하게 추린 차량·정비·다음 일정 요약, 사용자가 확인한 분석 입력을 보냅니다. 주소·좌표·메모·일정 제목·개인식별자를 기록에서 자동으로 보내지 않습니다. 사용자가 질문에 직접 적은 내용은 전송되므로 화면에서 전송 정보를 안내합니다.

가격·거리·시간 등의 숫자는 서버가 정리한 계산 근거에서 표시합니다. GPT가 만든 설명과 근거 ID는 검증하며, 지원하지 않는 숫자나 근거는 답변을 유보합니다. 이 검증이 모든 오류나 환각을 없앤다는 뜻은 아닙니다.

가격 조건에서 연료·배기량은 구동 방식이나 사진으로 추정하지 않습니다. 월 1,000km는 변경 가능한 초기 가정이며, 월 유지비는 사용자가 입력하는 가정입니다. 실제 지출이나 정비 견적이 아닙니다.

홈에는 **같은 로그인 세션·차량 스냅샷**에서 받은 검증된 분석 결과만 표시합니다. 모델을 실행하지 않았거나 제공 조건을 벗어나면 가격을 만들지 않습니다. 차량 정보가 바뀌거나 다른 계정으로 로그인하면 이전 결과를 그 차량의 가격으로 보여주지 않습니다. 캐시는 메모리에만 보관하며 분석 시 자동으로 영구 저장하지 않습니다.

상담 대화도 메모리에 두고 차량·계정 변경 시 비웁니다. 로그인 토큰과 비밀번호는 기기 저장소에 보관하지 않으므로 앱·페이지를 다시 열면 재로그인해야 합니다. 차량 정보의 계정 저장과 전체 기록의 동기화는 다릅니다. 주행·정비·계획 기록의 서버 백업은 사용자가 직접 저장·복원합니다.

## 참고 자료와 과거 결과

로그인 후 **내 계정 → 참고 자료**를 펼치면 다음 화면으로 이동합니다.

- **가격 분석 상세** (`/analysis`): 기존 비교 화면과 데이터·모델 집계. 오프라인 가치 비교의 합성 규칙 가격은 새 홈의 ML 가격과 별개입니다.
- **프로젝트 자료** (`/documents`): 기존 문서 검색. 화면에 들어왔다는 사실만으로 권한이 생기지 않으며 서버가 허용 계정을 검사합니다.

이동은 앱 내부 탐색으로 처리해 메모리 로그인 세션을 유지합니다. 직접 주소를 새로 여는 것은 페이지 재시작이므로 다시 로그인할 수 있습니다.

온비드 모델은 소비자 시세가 아닌 공매 낙찰가격을 다룹니다. 미래 값은 시장 조건을 고정하고 차령·주행거리를 바꾼 보유 시나리오이며 최적 매도일이나 실제 미래 시장가격을 입증하지 않습니다. 정비 알림의 주기는 예시 기준입니다. 모델 표본·지원 범위·오차와 화면의 가정 표시를 함께 봐야 합니다.

기존 2,197행 서비스 모델, 14,867행 평가 후보, 6개 문서·83개 청크의 RAG 검증은 서로 다른 범위입니다. 이번 UI 정리가 모델 승격·자료 확대·새 성능 검증을 의미하지 않습니다. 이전 [데스크톱](evidence/2026-11-04/current-ui-desktop.png)·[모바일](evidence/2026-11-04/current-ui-mobile.png) 이미지는 UI 03 이전 기록이며 새 화면 증거가 아닙니다.

## 로컬 검증 범위

이 문서 작성 시점에 확인한 검사입니다. 모두 합성 계정·응답을 사용했으며 실제 운영 로그인, 새 상담의 유료 GPT 호출, 현대 실차 API를 실행하지 않았습니다.

- 통합 TypeScript 검사와 변경한 계정·차량 화면의 ESLint 검사 통과.
- 데스크톱과 360px에서 계정 오류·회원가입·로그아웃·비밀번호 변경, 가입→차량 저장 실패 후 재시도, 세션 소실 시 재로그인, 기기 관리·초기화 확인 등 12회 통과.
- 정적 웹 빌드에서 데스크톱·모바일 카탈로그 2회 통과. 차종 선택, 필수 연식 검증, 사진·주행거리 저장과 새로고침 후 유지를 확인했습니다. 새 탭의 비활성 화면까지 선택하던 검사 구문은 현재 차량 영역으로 제한했습니다.
- 일반 상담 로컬 검사: Python 상담 8개와 기존 설명 8개, Java 상담 API 5개, TypeScript 도메인 4개 통과. 실제 OpenAI 응답 품질 검증과 새 운영 배포는 별도입니다.
- 일반 상담 정적 웹 검사 4회 통과: 자유 질문, 가격 근거·지원 보류, 홈 캐시, 차량 전환·로그아웃 시 결과 제거. 360·390·1440px에서 가로 넘침이 없고 입력창이 첫 화면에 보이는지 확인했습니다.

전체 통합·정적 웹 빌드·원격 CI의 최종 결과는 해당 실행 기록을 따릅니다. 브라우저 360px 검증을 Android/iOS 실기기 검증으로 표현하지 않습니다. 이전 APK의 에뮬레이터 설치·렌더링 관측은 이전 버전에만 해당하며, 웹의 같은 계정 위치 중계는 네이티브 APK에서 아직 지원하지 않습니다.
