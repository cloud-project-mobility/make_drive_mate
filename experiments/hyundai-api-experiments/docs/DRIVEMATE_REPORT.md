## 기능별 범위

| 기능 | 구현 가능한 부분 | 아직 필요한 확인 |
|---|---|---|
| 차량 등록 | 실차 carlist의 carId·차종 코드·판매 모델명 등을 내부 차량에 연결하는 설계 | 사용자 OAuth, 차량별 접근 동의, carlist 실제 응답. 현재 콘솔에 Sample 버튼이 보이지 않음 |
| 누적거리 | 거리·단위·조회일자·공급자 전송시각을 검증하는 Python 모델과 CLI | 공식 Sample/실차 응답, 시간대, 최신성·갱신 지연 |
| 경고등 6종 | 개별 boolean 표시, 미수신/오래된 정보/오류 구분 | 실제 지원 차종과 관측 지연. 경고 해제는 전체 정상 판정 아님 |
| 주행 가능 거리·EV | 거리·SOC·충전 여부/연결 여부·예상 충전시간 모델 | 실제 데이터, 차량별 지원 여부·갱신 조건 |
| 정비 판단 | 근거를 갖춘 정보 표시 설계 | 차종별 매뉴얼·정비 주기·교체 이력·운행조건 |

이번 11개 조회 항목은 엔진오일 수명/성분, 타이어별 실제 압력, 브레이크 마모량,
배터리 건강도(SOH), 전체 정비 이력을 주지 않습니다. 해당 값을 경고등에서 추정해 획득한 데이터처럼 쓰지 않습니다.
carlist는 상세 연식·트림·옵션 전체를 보장하지 않습니다. 다른 제원 API의 존재·사용 권한을 확인하지 않은 상태에서
현대 API 전체가 세부 사양을 제공하지 않는다고도 단정하지 않습니다.

## 거리·시각·null 처리

누적거리는 시동 종료 기준, 주행 가능 거리는 시동 종료 기준 및 2개월 미운행 시 조회 불가가 문서상 조건입니다.
주유 경고는 시동 종료, 다른 요청 경고는 시동/EV·PHEV 충전 종료 기준입니다. EV 두 API의 실제 갱신 간격은 미확인입니다.
공급자 전송시각, 조회일자, 서버 received_at을 별도 저장 후보로 둡니다. 공급자 시간대를 임의로 한국/UTC로 지정하지 않습니다.
null/누락/알 수 없는 단위를 0이나 false로 채우지 않습니다. UI는 마지막 정상 관측과 현재 실패 상태를 함께 표시하고
정비 관련 판단에서 오래되거나 불확실한 관측을 구분해야 합니다.

## API 누적거리와 GPS 중복 방지

계기 누적값은 기준 관측, GPS 거리는 구간별 추정치, 수동 입력은 별도 출처입니다.
**API 누적값에 완료된 GPS 주행거리를 다시 더하지 않습니다.** DriveMate의 완료 주행 1회 반영 규칙을 보존하되
공급자 기준값을 갱신할 때 이미 포함된 주행을 다시 적립하지 않는 화해 절차가 필요합니다.
관측 시간대가 불명확한 현재에는 자동 구간 정렬/합산을 보류하고 마지막 기준값과 잠정 GPS 추정을 따로 표시합니다.
거리 감소는 차량 변경·계기 교체·데이터 오류 검토 대상으로 두며 음수 주행을 만들지 않습니다.
샘플 차량은 실제 차량과 저장·집계·정비 알림에서 분리합니다.

## 실차 전환

[공식 연동 가이드](https://developers.hyundai.com/web/v1/hyundai/guide_api)에 맞춰 프로젝트 승인 범위,
등록 Redirect URI, 통합계정 로그인, state 검증, authorization code, 서버 측 토큰 발급/갱신/삭제,
개인정보 제공 동의·철회, 차량별 접근 권한, 조회 불가 콜백을 별도 구현해야 합니다.
Sample 토큰은 실차 토큰으로 재사용하지 않습니다. 데이터 API와 인증 API의 호스트도 공식 표시를 각각 확인해야 합니다.
문서상 개인 access token 24시간/refresh token 1년은 개인 OAuth 규격이며 Sample 만료 정책으로 전용하지 않습니다.
제공된 DriveMate 콘솔의 승인 항목 19개는 공개 규격 식별자 19개와 일치합니다.

## Spring Boot·PostgreSQL로 이전

외부 DTO와 내부 모델을 분리합니다. Python Decimal은 Java BigDecimal/PostgreSQL numeric,
단위·결과 출처는 명시적 enum, boolean의 미확인은 Boolean/null 또는 별도 품질 상태로 표현합니다.
공급자 시각은 원문 + LocalDateTime, 수신시각은 Instant/timestamptz입니다. timezone 확인 전 공급자 시각을 UTC로 바꾸지 않습니다.

| 저장 후보 | 주요 필드 |
|---|---|
| vehicle_link | 내부 UUID, 보호된 공급자 매핑, 사용자/차량 접근·동의 상태 |
| vehicle_observation | API 종류, SAMPLE/REAL/MOCK, 값 numeric, 원래 단위, 원천 시각 문자열/시간대 확인 여부, received_at, 품질 상태 |
| api_attempt | API 이름, 요청시각, HTTP·공급자 코드, 응답시간, 검증 결과. 토큰/원문 없음 |
| maintenance_event | 사용자 확인 정비 항목, 교체일·당시 누적거리, 근거 문서 |

이는 저장 권한·보유기간·캐시 TTL·철회 시 파기 범위 확인 후의 설계 후보이며 DB 구축 완료를 뜻하지 않습니다.
기존 DriveMate Sample 브랜치는 원격 Sample에 is_mock도 표시하고 있어 외부 DTO의 transport/source 구분을
정리할 필요가 있습니다. 이 실험에서는 SAMPLE과 자체 MOCK을 명확하게 분리합니다.

## GPT에 전달할 정보

현재 즉시 쓸 수 있는 것은 직접 만든 합성 Mock, 비밀값 없는 오류 분류, 이용 가능한 범위의 일반 설명입니다.
실차 관측은 계약·사용자 동의·목적·제3자 전송 조건을 확인한 뒤 필요한 항목만 최소화해야 합니다.
토큰·차량 ID·VIN·계정 정보·개인 이동 경로는 본 실험에서 GPT로 전달하지 않습니다.
정비 상담에는 허가된 차종/연식별 매뉴얼, 제조사 정비 주기, 사용자 제공 정비/교체 기록과 당시 계기값을
별도 확보해야 합니다. 정비 근거가 없으면 추천의 불확실성을 표시하고 센서/정비 기록을 만들어내지 않습니다.

확인된 제한은 프로젝트별 일별 API 제한의 존재입니다. 수치·Sample 적용 조건·캐시·응답 저장/공유·외부 AI 허용은 미확인입니다.
세부 조건은 [보안/계약 문서](CONTRACT_AND_SECURITY.md)에 정리했습니다.
