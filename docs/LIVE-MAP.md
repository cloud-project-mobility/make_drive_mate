# 기기 위치 웹 지도

`LiveLocationMap`은 부모의 위치 공유 기능이 전달한 이 기기와 같은 계정 기기 최대 2개의 좌표를 표시한다. GPS 권한을 직접 요청하거나 위치를 수집하지 않는다. 차량에 설치된 장치의 위치로 설명하지 않는다.

웹에서는 **카카오 지도 연결** 버튼을 눌러야 SDK를 요청한다. SDK URL에는 공개 JavaScript 키만 들어가고 좌표는 들어가지 않는다. 실제 지도를 만들면 표시 지역의 지도 타일을 카카오에서 받아오므로 화면에서 이를 먼저 알린다. 서버 비밀 키·카카오 REST 키는 사용하지 않는다.

- 빌드 설정: `EXPO_PUBLIC_KAKAO_JAVASCRIPT_KEY`. 공개 웹 키이며 JavaScript 번들에서 확인 가능하다. 실제 값은 소스·예제 파일에 기록하지 않는다.
- 카카오 앱의 JavaScript SDK 허용 도메인에는 실제 웹 서비스의 프로토콜·호스트·포트를 등록해야 한다.
- 카카오 앱의 `[카카오맵] > [사용 설정]` 상태를 `ON`으로 설정해야 한다. 현재 정책상 앱의 활성화 순서와 무료 쿼터 초과 여부에 따라 유료 API 설정이 필요할 수 있으므로 운영 계정의 설정을 확인한다. 이 구현 작업에서 해당 설정을 변경하거나 유효성을 검증하지 않았다.
- 키가 없거나 SDK 요청이 실패하면 지도 미연결로 표시한다. SDK 로딩 15초, 최초 타일 로딩 20초 제한 후 일반적인 설정·네트워크 확인 문구를 표시한다. 오류 문구에 요청 URL이나 키를 포함하지 않는다.
- GPS/공유 위치가 없으면 임의의 현재 위치를 만들지 않는다. 위치가 모두 삭제되거나 지도를 닫으면 마커·라벨과 화면을 지우고 좌표 갱신을 멈춘다. 이미 받은 SDK 코드 자체는 브라우저에 남을 수 있다.
- 네이티브에서는 사용자가 누른 기기의 좌표로 외부 카카오 지도를 연다. 해당 버튼도 좌표 전달을 미리 안내한다.

공식 근거: [JavaScript 키·허용 도메인·지도 생성](https://apis.map.kakao.com/web/guide/), [동적 로딩과 지도 이벤트](https://apis.map.kakao.com/web/documentation/#load), [마커 제거](https://apis.map.kakao.com/web/sample/multipleMarkerControl/). 현재 위치는 위도, 경도 순서의 WGS84 좌표를 사용한다.

운영 활성화·쿼터의 기준은 [카카오맵 공식 사용 방법](https://developers.kakao.com/docs/ko/kakaomap/common)을 따른다. 카카오 로그인용 JavaScript SDK와 지도 SDK는 별개이며, 이 컴포넌트는 지도 SDK만 불러온다.

CI/CD에서도 웹 export 단계에 같은 `EXPO_PUBLIC_KAKAO_JAVASCRIPT_KEY`를 전달해야 한다. 공개 웹 설정값이므로 GitHub Actions의 해당 변수로 관리할 수 있지만, REST 키·관리자 키·GPT 키를 이 변수에 넣으면 안 된다. Expo는 빌드 시 값을 번들에 넣으므로 EC2 실행 환경에만 값을 추가해도 이미 만들어진 웹 파일에는 반영되지 않는다. 키를 주입하지 않은 CI 검사 산출물은 지도 미연결 상태가 정상이며, 실제 배포용 빌드는 공개 키를 주입해 다시 생성해야 한다. 배포 패키지 검사에서 허용하는 값도 이 공개 JavaScript 키 하나로 한정한다.

단위 검사는 합성 좌표·가짜 SDK만 사용한다. 실제 사용자 위치, 실제 키 또는 외부 지도 호출을 검증에 사용하지 않는다. 실제 도메인에서의 지도 승인은 운영 설정 확인 후 별도로 검증해야 한다.
