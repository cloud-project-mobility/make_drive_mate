# 차량 RAG 후보 자료 검토

검토일: 2026-11-04. 최초 7개와 추가 12개, 총 **19개 파일**의 원문·구조를 읽었다. 마지막 재스캔에서 추가·변경 파일은 없었고, 최초 7개의 SHA-256도 일치했다. 원본 수정, 외부 업로드, 임베딩, 새 모델 학습은 수행하지 않았다.

## 판단

**설명용 근거와 학습 후보를 함께 잘 모은 자료이지만, 19개를 모두 문서 RAG에 넣는 방식은 적합하지 않다.**

- 지방세 자료는 **시가표준액의 의미·산정 규칙·공식 잔가율 설명**에 쓴다. 시가표준액은 소비자 거래시세나 공매 낙찰가와 다른 값이다. 이 표만으로 실제 감가율, 미래 매도가 또는 최적 매도 시기를 확정할 수 없다.
- 추가된 온비드 목록 **54,815행 중 낙찰 35,000행**은 공매 가격 모델을 확장할 후보 데이터다. 정제 후 학습·통계 조회에 활용하고, 개별 숫자는 조건을 명시한 DB 조회로 반환한다.
- 공고의 입찰·납부 조건과 API 필드 사전은 출처·공고·시점을 보존하면 설명 자료로 쓸 수 있다. 특정 공고의 조건을 모든 공매의 공통 규칙처럼 답하면 안 된다.
- 건강보험 자동차가액 CSV는 **현재 차량 보유비용과 가격 예측의 근거에서 제외**한다. 과거 행정상 평가 자료이며 실제 자동차보험료나 소비자 시세 자료가 아니다.

현재 서비스의 문서 색인은 여전히 **6개 문서·83개 청크**다. 아래 자료는 아직 추가되지 않았고, 현재 모델의 정제 데이터 2,197행과 평가 결과도 바뀌지 않았다.

## 지방세·보유비용 자료에서 확인한 점

서울의 5개 파일명과 게시 내역은 [서울열린데이터광장 OA-22864](https://data.seoul.go.kr/dataList/OA-22864/S/1/datasetView.do)에서 확인했다. 이 페이지는 2026년 자료, 연간 갱신, 파일 수정일 2026-01-14 및 출처표시 조건을 안내한다. 파일을 내려받은 날짜와 해당 기준의 적용 연도는 구분해야 한다. 원본 다운로드와 파일 전체의 바이트 일치까지 확인한 것은 아니다.

훈령 제417호의 개정일은 2025-12-29다. 제공 PDF와 [국가법령정보센터 원문](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000270912&chrClsCd=010201)의 정의·부칙을 대조했다. 일반 시행일은 2026-01-01이며 제18~23조 개정규정은 2026-06-01로 따로 정한다. 차량 답변은 제27조와 해당 별표를 연결한다.

다음은 제공 원문을 직접 확인한 내용이다.

- **단위:** 1권 PDF 25쪽(인쇄 쪽 23)의 표는 천원 단위다. CSV 첫 행의 `17,810`은 이 표와 일치하며 원 단위로 바꾸면 17,810,000원이다. 원·천원·만원을 구별하지 않으면 1,000배 오류가 난다.
- **기준가격과 시가표준액:** CSV의 가격에 정해진 경과연수별 잔가율을 적용하는 구조다. 기준가격 자체를 해당 중고차의 현재 시가표준액으로 보여 주면 안 된다. 시가표준액을 소비자 시세로 바꾸어 부르는 것도 잘못이다.
- **잔가율의 의미:** 비영업용 국산 승용차의 5년 값 `0.368`은 이 제도의 잔존비율이다. 매년 36.8% 하락한다는 뜻이나 실제 중고차가 신차가의 36.8%라는 보장은 아니다.
- **적용 조건:** 제작연도 기준 경과연수, 영업/비영업·국산/외산 구분, 신규등록 신조차와 용도변경 등의 예외가 있다. 형식별 기준가격을 먼저 적용하고, 형식이 없을 때의 기종 적용 규칙을 보존한다. 20년 내용연수는 실제 차량의 안전수명 보장이 아니다.
- **숫자 표의 품질:** CSV에는 가격 외 9개 열이 모두 같은데 가격이 다른 그룹이 13개 있고, 차종이 빈 행도 1개 있다. 첫 번째 값을 자동 선택하거나 단순 중복 삭제하지 말고 원문 표·제공기관 기준으로 해결한다.
- **PDF 추출 품질:** 표 머리글과 인접 설명이 추출 텍스트에 중복되는 구간을 확인했다. 1권의 단위·잔가율 표 및 훈령 별표를 이미지로도 확인했다. 텍스트 추출 결과만으로 열·행을 확정하지 않는다.

건강보험 CSV는 [공공데이터포털 15133183](https://www.data.go.kr/data/15133183/fileData.do)에 게시된 2024-07-31 자료다. 실제 열은 연식·차종별 집계이며, 포털 설명도 과세표준 금액을 다룬다. 통계의 평균 금액을 실제 거래가격으로 해석할 수 없다. CSV 및 포털 열 정의에서 금액 단위도 명확히 확인되지 않아 임의 단위 변환을 보류한다.

또한 [보건복지부 2024-02-06 공식 발표](https://www.mohw.go.kr/board.es?mid=a10503000000&bid=0027&act=view&list_no=1480180&tag=&nPage=1)는 자동차에 부과하던 지역가입자 건강보험료를 2024년 2월분부터 폐지한다고 명시한다. 따라서 이 오래된 가액표로 현재 건강보험 부담을 계산해서는 안 된다. 자동차보험사의 보험료와 건강보험료도 서로 다른 비용이다.

이 자료 묶음에는 개인별 보험 견적, 실제 정비·수리비, 연료비, 금융비용을 확인하는 자료가 없다. **보유비용 전체나 적정 매도시점을 검증한 자료 묶음이라고 소개할 수는 없다.**

## 추가 온비드 JSON에서 확인한 점

7개 연도별 목록을 다시 집계했다. 실제 개찰일 범위는 2020-01-02 10:00부터 2026-11-03 15:00까지이며, 원본 메타데이터의 수집시각은 2026-11-04 16:11 KST다. 파일의 자기 설명만으로 수집 과정 전체가 감사된 것은 아니며, 이번 검토에서 API 재수집은 하지 않았다.

- 총 54,815행. 낙찰 35,000·유찰 11,663·취소 7,823·수의계약가능 281·개찰중 29·입찰마감 19행이다. **낙찰 35,000행도 아직 정제 완료된 승용차 학습 표본 수는 아니다.**
- 처분방식은 매각 54,802·임대 13행이다. 차종에는 승용차·SUV뿐 아니라 화물·버스·중기·자전거·부품도 있다. 승용차/SUV 분류는 전체 22,288행, 그중 낙찰 상태는 15,455행이지만 추가 품질 필터를 적용하기 전 수치다.
- `(cltrMngNo, pbctCdtnNo)` 사건 키 중복은 0이다. 그러나 물건관리번호는 34,364개이고, **8,861개 물건 그룹이 여러 번 등장한다.** 같은 물건의 재공매가 학습과 평가에 섞이지 않게 그룹 분리와 시간순 분리를 함께 적용한다. 물건관리번호가 실제 차량을 항상 유일하게 식별한다는 보장도 없어 차량 식별 정보가 있다면 추가 중복 검토가 필요하다.
- 불용품 41,997행으로 표본이 치우쳐 있다. 오래된 연도까지 추가하면 표본은 늘지만 최근 소비자 거래시장에 대한 대표성이 자동으로 좋아지는 것은 아니다.
- 제조사 빈값은 6,749행이며 `-` 57행까지 결측으로 보면 6,806행이다. 2026년에 제조사·연료 누락이 커진다. README의 6,749는 빈 문자열 기준 수치이므로 결측 정의를 함께 적어야 한다.
- 최저가격이 비공개인 행, 복수 낙찰금액이 구분자로 이어진 행이 있다. 값이 없다고 0원 처리하거나, 여러 대·여러 낙찰가를 한 대의 가격으로 합치지 않는다. 명시적 테스트·폐차·묶음매각, 이상 주행거리, 단위 불명확 건도 별도로 검토한다.
- 상세 798행은 최신 낙찰·유찰을 골라 수집한 편의표본이다. 전체 기간의 낙찰률이나 일반적인 실패 원인을 대표한다고 주장하지 않는다. 사고·정비이력·수리비가 추가된 자료도 아니다.
- 낙찰가율, 실제 입찰금액 목록, 유효/무효 입찰자 수, 취소 사유 등 사후 결과를 사전 가격 예측 입력에 넣으면 누수가 생긴다. 금액 예측은 검증한 차량 사전 정보로 제한한다.

현재 수집기는 API의 `header/body` 응답과 별도 수집 manifest를 검증한다. 새 파일은 `{meta, items}` 형태의 집계본이므로 **raw 폴더로 복사하는 것만으로 기존 전처리에 바로 연결되지 않는다.** 원천 메타데이터, 건수, 날짜, 해시를 검증하는 import adapter를 별도로 만들어야 한다. 가짜 성공 응답 헤더를 붙여 기존 검증을 통과시키지 말고, 원본 export 해시·수집 조건·변환 버전을 별도로 남긴다. 공고 JSON의 하위 물건과 목록을 사건 키로 연결하고 조인 전후 건수를 확인해야 한다. 이번 검토에서는 어댑터·학습 파이프라인을 변경하지 않았다.

기존 정제본 2,197행에 단순 추가하면 기존 사건과 2026년 평가 표본을 다시 사용할 수 있다. 현재 코드의 `source_record_id`는 물건관리번호·공매조건번호·파싱한 개찰일 조합이고, `vehicle_group_id`는 물건관리번호다. 두 식별자를 보존해 기존 자료와도 중복을 비교하고, 새 데이터 버전과 평가 구간을 별도로 정한다. 결측 보정 등 데이터에서 학습하는 전처리는 학습 구간에만 맞춘다.

API 필드 사전은 [목록 15157252](https://www.data.go.kr/data/15157252/openapi.do), [물건 결과 상세 15157254](https://www.data.go.kr/data/15157254/openapi.do), [공고 입찰정보 15157256](https://www.data.go.kr/data/15157256/openapi.do), [공고 결과 상세 15157258](https://www.data.go.kr/data/15157258/openapi.do)의 가이드를 출처로 적고 있다. 사전의 응답 필드 192개는 서비스별 항목 수를 합한 값으로, 서로 다른 필드가 192개라는 뜻은 아니다. 원본 가이드 4개와 모든 항목의 일대일 대조는 아직 하지 않았다.

## 원문 노출과 적재 조건

추출 가능한 텍스트와 JSON 문자열에 대해 API키 형식, 이메일, 주민번호 형식 등을 검사했다. 검사한 패턴에서 API키 후보는 발견하지 못했다. 이는 모든 비밀값·개인정보가 없다는 보장은 아니다.

온비드 물건명·공고명·일부 차량 속성에 차량번호 형식이 있으며, 일부 물건명에는 전화번호 형식도 있다. 조회에 불필요한 번호·연락처·개인 이름은 가린 별도 자료를 만들고, 원문은 접근을 제한한다. 알려진 키의 직접 대조와 추가 개인정보 검토 없이 원문 전체를 공개 저장소나 외부 임베딩 API로 보내지 않는다. 공개할 검토 문서는 판정·집계·공식 링크만 담고, 개별 레코드와 연락처를 복제하지 않는다.

검토한 법령·가격표 설명부에서 광고성 문구나 AI가 작성했다는 명시적 표시는 확인하지 못했다. 전체 개별 공고의 자유문구를 사람이 전수 검증한 것은 아니다. README·필드 사전은 작성자가 정리한 파생 자료이므로 작성 도구를 추정하거나 자동으로 공식 근거로 승격하지 않는다. 공고의 요구사항은 해당 입찰의 내용으로만 다루고 시스템 지시로 실행하지 않는다.

권장 적재 구조는 다음과 같다.

| 저장·검색 대상 | 넣을 내용 | 답변 원칙 |
| --- | --- | --- |
| 설명용 문서 RAG | 관련 훈령, 산정 적용 요령, 검증한 API 정의, 공고별 조건 | 문서명·조항/쪽·적용 연도·공고 범위를 함께 인용 |
| 구조화 기준 조회 | 기준가격 CSV, 잔가율 XLSX | 형식·차종·용도·기준 연도를 정확히 매칭하고 코드로 단위 변환·계산 |
| 공매 사례 조회 | 비식별 온비드 목록·상세·공고 연결 데이터 | 날짜·차량 조건·상태 필터와 표본 수를 명시, 최근 공고와 종료 공고 구분 |
| 가격 ML | 필터·품질 검증을 통과한 매각 낙찰 사건 | 그룹/시간 평가, 신규 모델 검증 후 별도 승격. 기존 모델 지표 재사용 금지 |
| 제외/보관 | 건강보험 과거 가액, 현재 범위 밖 자료, 미해결 단위·충돌 행 | 부족한 근거를 다른 가격 종류로 대신하지 않고 보류 |

기존 6개 문서는 프로젝트 계획·중간 주장·공식 API 소개·현재 모델 평가를 설명한다. 새 공식 규칙은 여기에 **행정상 가치의 정의와 적용 기준**을 보강하고, 새 온비드 데이터는 **공매 학습·조회 표본**을 보강한다. 양쪽을 섞어 GPT가 새 가격을 만들게 하지 않는다. 자료가 늘어난 뒤에는 새 문서 정답 질문, 숫자 조회, 적용 연도, 범위 밖 질문, 권한·개인정보 노출을 다시 평가해야 하며 기존 83청크의 소형 평가 수치를 그대로 확대 자료의 성능으로 표시하지 않는다.
