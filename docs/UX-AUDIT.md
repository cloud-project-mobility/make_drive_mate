# DriveMate 원안 전수 검토

사용자가 제공한 Penpot 원안(공유 링크 비공개)의 17개 화면을 2026-10-21에 확인했다. 공유 파일의 실제 텍스트, 도형 크기, 클릭 목적지를 추출하고 Chromium으로 모든 화면을 390 × 844 해상도에서 렌더링했다. 다음 내용은 원안에 근거한 전문가 검토다. 실제 사용자를 모집한 사용성 조사나 도로 주행 실험을 수행했다는 뜻은 아니다.

## 화면을 가로지르는 개선

- **일관된 탐색:** 원안 차고에서는 ‘일정’, 상세에서는 ‘이동 계획’이며 목적지도 다르다. 동일한 탭 이름·목적지를 유지한다.
- **터치 영역과 접근성:** 원안의 하단 탭 27개는 높이 18px의 텍스트 도형에 클릭이 연결되어 있다. 앱에서는 아이콘과 레이블을 포함한 충분한 전체 영역을 누를 수 있도록 하고 선택 상태, 입력 레이블, 키보드 포커스를 제공한다. 원자료에는 버튼 배경과 레이블의 중복 상호작용도 있으므로 작은 도형 수 전체를 서로 다른 버튼 수로 해석하지 않았다.
- **레이아웃 회복력:** 390 × 844 고정 배치와 작은 보조 텍스트를 가변 너비·스크롤·안전 영역에 맞춘다. 긴 한글 이름, 좁은 화면, 키보드가 올라온 상태에서도 주요 동작에 도달할 수 있어야 한다.
- **데이터 신뢰:** 원안은 모든 상호작용이 고정 화면 이동이다. 실제 구현은 차량·일정·정비·주행·설정을 함께 갱신하고 재실행 후 복구해야 한다. 저장 실패를 성공으로 처리하지 않는다.
- **실제 기능과 예시의 구분:** 로컬 데이터, 예시 일정, 추정 경로, 실제 GPS 측정과 외부 서비스 연동을 혼동하지 않는다. 백엔드·OAuth·실시간 도로 경로가 없는 경우 제공한다고 주장하지 않는다.

## 자산 출처

차량 이미지 세 장은 사용자가 지정한 Penpot 공유 파일의 원본 PNG를 수정하지 않고 복사했다. 추출일은 2026-10-21이다. 파일 권리 또는 라이선스를 새로 부여하는 의미는 아니며, 원본 디자인 자산으로 출처를 남긴다.

| ---------------------------- | -------------------------------------- | -------------------- |
| `assets/vehicles/ice.png`    | `52a5041f-08a1-80f1-8008-c426b96bd3ef` | 1536 × 1024 RGBA PNG |
| `assets/vehicles/hybrid.png` | `17193a1f-939a-80b5-8008-c426bab2063a` | 1536 × 1024 RGBA PNG |
| `assets/vehicles/ev.png`     | `52a5041f-08a1-80f1-8008-c426bc085199` | 1536 × 1024 RGBA PNG |

원안의 지도 래스터는 전수 검토 화면 모음에만 포함했다. 라이브 지도 자산이나 경로 계산 결과로 재사용하지 않았다. 원안의 지도에는 OpenFreeMap · © OpenMapTiles · © OpenStreetMap 출처가 표시되어 있다.

## 구현에서 의도적으로 바꾼 흐름

- **로그인·회원가입 → 로컬 시작 / 예시 체험:** 인증 서버나 Google OAuth가 없는 상태에서 로그인 완료를 흉내 내지 않는다. ‘내 차량으로 시작하기’는 빈 차고, ‘예시 차량으로 둘러보기’는 원안의 세 차량을 연다. 차량·정비·주행·설정은 현재 기기에 저장된다.
- **고정된 화면 변형 → 실제 차량 상태:** 0·1·2·3대 화면을 별도로 복제하지 않고 등록, 선택, 수정, 삭제 결과로 렌더링한다. 동일한 차량 ID를 유지해 차고·정비·주행의 이름과 주행거리를 일치시킨다.
- **Google 일정 목업 → 직접 입력하는 날짜 기반 계획:** 계정 연결 없이 일정 이름·도착 날짜·시간·출발지·도착지를 입력한다. 예시 일정은 명시적으로 선택할 수 있다. 기본 도보/여유 시간은 새 계획에 적용하며 이미 저장한 계획을 조용히 바꾸지 않는다.
- **실제 지도처럼 보이는 이미지 → 경로 개요 + 지도 앱 열기:** 앱 내부 그림은 ‘실제 지도 아님’으로 표시하고 실제 경로 확인은 Google Maps로 연결한다. 입력한 예상 운전 시간으로 출발 시간을 계산하며, 실시간 교통·자동 최단거리 계산·5분마다 경로 갱신은 제공한다고 표시하지 않는다.
- **정적인 GPS 숫자 → 권한을 받은 포그라운드 기록:** 시작·일시 정지·재개·완료를 구분한다. 화면을 벗어나면 기록을 멈추고, 복귀 후 직접 재개한다. 허용되지 않은 위치 권한에는 복구 방법을 안내한다. 멈춘 구간과 부정확한 위치를 추정 거리로 더하지 않는다.
- **알림 예시 → 계획 목록과 모바일 예약:** 웹에서는 앱 내 출발 계획을 확인한다. 모바일 기기 알림은 명시적으로 켤 때 권한을 요청하며 실제 예약 결과를 표시한다. 삭제한 계획/차량에 연결된 예약 알림도 해제한다.

## 구현 검증 기록

2026-10-21에 Chromium 데스크톱·모바일 설정 각각으로 9개 시나리오, 총 **18개 Playwright 테스트가 통과**했다. 최종 18개 전체 실행이 통과했고, 별도로 저장 실패·손상 데이터 복구·직접 링크 보호 테스트도 추가했다. [테스트 코드](../tests/e2e/app.spec.ts)는 접근성 역할·레이블로 실제 UI를 조작하며, 초기 상태를 저장소에 주입하지 않는다.

검증한 내용은 EV/HYB 선택 후 일관된 차량 정보와 소모품 목록, 빈 차고 등록·잘못된 입력·최대 3대·재실행, 미래 정비일/현재 거리 초과 거부와 정비 저장, 자정을 넘는 출발 시간과 계획 저장, 실제 브라우저 위치 권한 거부, 설정 저장과 새 계획 반영, 360px 및 데스크톱에서의 가로 넘침, 위치 기록 복구·저장, 실제 백업 파일 다운로드·잘못된 내용 거부·확인 후 복원·재실행이다.

위치 기록 테스트에서는 **브라우저에 주입한 좌표**를 사용했다. 약 111m를 기록한 뒤 정지하고, 정지 중 약 1.4km 이동시킨 뒤 페이지를 다시 열어도 기록은 약 111m였다. 재개 후 약 111m를 더 이동해 총 약 222m만 저장했으며 아반떼 누적 거리는 화면에 48,250.2km로 표시되고 재실행 후에도 유지됐다. 이는 기록 로직과 브라우저 연동 검증이며 실제 센서 정확도, 장거리 도로 주행, iOS/Android 권한 및 OS 알림 전달까지 실증했다는 뜻은 아니다.
