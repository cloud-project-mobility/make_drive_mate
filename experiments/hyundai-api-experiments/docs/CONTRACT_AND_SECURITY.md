# 응답 계약·보안·실패 처리

2026-11-25 현재 규격은 [API 목록](API_MATRIX.md)에서 확인합니다. 실제 Sample 데이터는 이번에 수신하지 못했습니다.
HTTP 200만으로 성공 처리하지 않습니다. errCode/errMsg/errId/error/errors 또는 명시적인 success=false가 있으면 실패이며,
성공 플래그가 없는 공식 데이터 응답은 HTTP 상태·오류 봉투 부재·필수 타입/구조를 함께 검증합니다.

## 모델 경계

- 누적거리 표는 odometers를 object로 적지만 공식 예시는 배열입니다. 예시의 비어 있지 않은 배열만 수용합니다.
- msgId와 각 API의 필수 필드를 검사합니다. 누적거리 행 하나라도 잘못되면 전체 응답을 사용하지 않습니다.
- 누락, null, 빈 배열, boolean을 숫자로 사용한 값, 음수, NaN/Infinity, 미상 단위, 잘못된 날짜는 실패입니다.
- 거리: 0 feet / 1 km / 2 meter / 3 miles. 임의 반올림·0 기본값·미상 단위 추정 없음.
- 충전 시간: 0 hour / 1 min / 2 msec / 3 sec. SOC는 0~100%. SOC는 SOH가 아닙니다.
- 공급자 timestamp는 시간대가 명시되지 않아 원문과 naive datetime으로 보존합니다. 수신시각은 별도 UTC datetime입니다.
- 경고등에는 공급자 관측시각이 없어 None입니다. 수신시각으로 채우지 않습니다.
- 경고 없음은 해당 경고에만 해당합니다. 차량 전체 정상·센서 정상·정비 불필요를 뜻하지 않습니다.
- 추가 필드는 무시하며 필수 필드 검증이 공급자의 전체 스키마나 실제 최신성을 보증하지 않습니다.

## 인증·전송·진단

.env만 읽고 환경변수 보간·부모 폴더 탐색·다른 프로젝트 토큰 사용을 하지 않습니다.
설정의 repr에는 실제 값이 없습니다. 허용된 고정 HTTPS 호스트와 경로만 사용하고,
carId에 경로 구분자/쿼리를 넣을 수 없게 검사합니다. OAuth Client Secret은 Sample에 보내지 않습니다.
TLS 검증을 끄지 않았으며 trust_env=False, 자동 리다이렉트/재시도 없음입니다.
401, 403, 429, 5xx, timeout, DNS/TLS/연결 오류, 잘못된 JSON을 구분합니다.
HTTP 401만으로 토큰 만료를 확정할 수 없습니다. 데이터 API 4011/4012는 공식 공통 오류 정의상 헤더/세션 오류이며,
정확한 만료 여부는 발급 이력과 공급자 응답이 필요합니다. 본 실험에는 실제 인증 실패/만료 증거가 없습니다.

로그는 허용 목록의 메타데이터만 남깁니다. Authorization·차량 ID·오류 원문·응답 본문은 저장하지 않습니다.
알려진 로컬 비밀값을 진단 문자열에서 추가 제거하고, 공급자 errCode도 정해진 4자리 형식만 허용합니다.
CLI는 HTTP 라이브러리 로그를 억제합니다. 추후 서비스에 연결할 때 요청/응답 debug trace를 켜지 마세요.

현재 로컬 .env는 빈 템플릿입니다. 재사용 코드에서 교체해야 할 실제 노출 비밀값은 발견하지 않았습니다.
이는 다른 저장소의 전체 Git 이력이나 외부 로그를 검사했다는 뜻이 아닙니다.
비밀정보 검사기는 로컬 .env 값·JWT·Bearer 리터럴·설정 값·개인키 패턴, Git의 민감 경로 추적을 검사하며
매칭 값은 출력하지 않습니다. 런타임·캐시·가상환경과 .env 자체는 검사 대상에서 제외합니다.

## 저장·캐시·외부 AI

2026-11-25 읽은 [공식 이용약관 페이지](https://developers.hyundai.com/web/v1/hyundai/terms_of_use)에는
서비스 데이터 추출·저장·보관 및 임의 제3자 제공/목적 외 처리에 관한 제한, 동의/보유기간과 파기 관련 조항이 있습니다.
프로젝트에 실제 적용되는 계약·예외·Sample 공유 조건·캐시 TTL·외부 AI 전송 허용은 확인되지 않았습니다.
본 프로젝트는 실제 차량 본문을 파일/DB/LLM에 보내는 기능을 만들지 않았습니다.
실제 응답 fixture가 없으며 향후 마스킹/가공 자료를 만들 때는 원본이 아님과 변경 내역을 명시해야 합니다.
공개 문서 조회 HTML은 로컬 output/research에만 있고 공개 대상에서 제외됩니다.

[공식 FAQ](https://developers.hyundai.com/web/v1/hyundai/faqs)는 개발 API의 프로젝트별 일별 호출 제한을 설명합니다.
정확한 수치·Sample 적용 여부·리셋 시각·응답 헤더는 미확인입니다. 429에 자동 재시도하지 않습니다.
TLS 오류를 우회하거나 다른 프로젝트/계정으로 제한을 우회하지 않습니다.
