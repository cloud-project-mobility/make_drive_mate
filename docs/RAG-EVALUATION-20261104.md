# 공개 ECS RAG 평가 — 2026-11-04

최종 [DriveMate HTTPS 서비스](https://d2a3l7qimjk3ir.cloudfront.net)에서 작성자가 정한 **근거 있는 질문 8개와 문서 밖 질문 2개**를 1회씩 실행했다. 사용자가 가림 처리된 검색 본문을 OpenAI에 보내는 답변 생성을 승인한 뒤 진행했으며, 원본 문서·검색 발췌·답변 본문·계정 정보는 이 공개 기록에 포함하지 않는다.

HTTP 요청 10건은 모두 200이었다. 근거 질문 8건은 `gpt-6-astra`로 답변했고, 문서 밖 질문 2건은 LLM 호출 없이 유보했다. **사전에 정한 자동 판정은 8/10이며 이 점수는 수정하지 않는다.** 추가 원문 대조에서는 답변 8건의 선택 근거가 모두 질문에 관련되고 충분했으며, 문서 밖 2건의 유보도 적합했다. 작은 작성자 시나리오 점검이며 독립적인 일반 정확도 평가가 아니다.

## 평가 방법과 질문

자동 판정은 응답 스키마, 예상 답변/유보 상태, 인용 ID 유효성, 인용문과 선택 원문의 정확한 일치, 사전에 지정한 문서 ID·키워드를 검사했다. 추가 검토는 선택된 발췌가 실제 질문에 관련되고 답을 뒷받침하는지를 직접 대조했다. 단순 원문 일치는 답의 관련성·충분성이나 문서 자체의 최신성을 증명하지 않는다.

## 해석 범위와 다음 평가

- 현재 6문서·83청크 프로젝트 지식 색인을 확인했다. 신규 차량 자료가 확대 반영됐다는 뜻은 아니다.
- 문서에 적힌 PoC 계획과 현재 운영 구현은 구분한다. 과거 계획의 비율이나 목업 설명을 정확히 검색해도 현재 코드의 동작을 자동 검증한 것은 아니다.
- 문서 밖 질문 2개는 모두 유보했지만, 일반적인 환각률이나 모든 문서 밖 질문의 차단 성능을 추정할 수 없다.
- 다음 평가에서는 허용 가능한 여러 출처를 실행 전에 지정하고, 새로운 질문·사용자 작성 질문·상충하거나 오래된 문서·답이 일부만 있는 질문을 포함한다.
- 이번 문서 검색 평가는 차량 가격 모델의 정확도, 미래 시장가격 또는 실제 ML 매도 추천을 검증하지 않는다.
