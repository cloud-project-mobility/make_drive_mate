# DriveMate 인수 메모

작성 기준: 2026-11-04. 현재 전달 기준은 **로컬 실행 완료, AWS 서비스 미배포**다. 실패한 AWS 배포 자원은 최종 암호화 백업을 보존한 뒤 정리했다. 공개 운영 URL은 없다. 원본 Word·PowerPoint 파일은 이번 작업에서 수정하지 않았다.

## 전달된 기능

사용자가 차량 조건을 입력하면 온비드 공매 낙찰 자료로 학습한 모델이 현재 조건의 참고 가격을 계산한다. 차령·예상 주행거리·입력 유지비를 바꿔 보유 조건을 비교하고, 데이터가 부족하면 가격 제시를 유보한다. 이는 소비자 중고차 시세나 확정 매입견적, 실제 미래 시장가격 예측이 아니다.

화면은 실제 공매 모델, 데이터 분석 집계, 기존 오프라인 합성 계산, 프로젝트 문서 근거 검색을 구분한다. GPT는 검증된 가격·사례 설명 또는 문서 출처를 선택하며 가격 자체를 생성하지 않는다.

## 구현과 증거

| 항목 | 확인된 내용 | 상태·한계 |
|---|---|---|

| 반복 분석 | 수집→원본 저장→전처리→모델 비교→집계·시각화 CLI 및 SQS worker | 새 후보 모델의 운영 자동 승격 없음 |
| 웹 | 실제 모델·분석·RAG 화면, HTTPS 동일 출처 API 기본값, 서버/계정 변경 시 결과 초기화 | 브라우저 검증은 모바일 실기기 검증이 아님 |

## 숫자를 보고하는 방법

| 가격 모델 평가 | 표본 | MAE | 함께 표시할 정보 |
|---|---:|---:|---|
| 전체 최종 시험 | 341건 | 236.15만원 | 모든 시험 자료에 대한 결과 |
| 사전에 정한 제공 조건에 맞는 부분집합 | 262건 | 134.74만원 | 제공률 76.83%, 79건 유보. 전체 결과를 대신하지 않음 |

정제 2,197행 중 시간 경계를 넘는 53개 차량 그룹·122행을 제외한 분할은 훈련 839, 검증 559, 구간 보정 336, 시험 341행이다. 차종·세대·사고·정비·트림 정보의 한계와 공매 표본 편향을 함께 설명한다. 조건부 MAE를 전체 정확도나 소비자 매입가격 정확도로 바꾸어 쓰지 않는다.

가격 유보는 미학습 모델·제조사 조합 또는 핵심 수치의 훈련 범위 이탈에 적용한다. 같은 모델의 훈련 표본이 10건 미만인 경우는 경고이며, 그 조건 하나만으로 자동 유보하지 않는다. 범위 안에 있다는 사실이 모든 차량 조합의 근거가 충분하다는 뜻은 아니다.

문서 검색은 개발자가 작성한 작은 확인용 질문 10개에서 Recall@1 0.70, Recall@3 0.90, Recall@6 0.90, MRR@6 0.7667이었다. 독립적인 일반 성능 시험이 아니다. 문서 밖 질문 3개는 실제 LLM 선택에서 3/3 보류했지만, 단순 유사도 게이트만으로는 3개 모두 통과했다. 따라서 “환각 0%”, “정확도 100%”, “문서 밖 질문 완벽 차단”으로 쓰지 않는다.

## 현재 실행과 AWS 상태

로컬 웹은 `http://127.0.0.1:8081`, Spring은 `http://127.0.0.1:18085`다. 실행한 PC에서만 접근할 수 있다. Spring의 계정 저장소는 H2이고 문서 검색은 `DRIVEMATE_RAG_BACKEND=local`을 명시했다. `pgvector`가 기본값이며 요청이 실패했다고 자동으로 local로 바꾸지 않는다. 실행·팀 분담 절차는 [TEAM-HANDOFF.md](TEAM-HANDOFF.md)를 따른다.

`backend/data/local-run/verification.json`에서 로그인 200, 예약 이메일 일반 가입 403(`email_reserved`), 실제 ML+GPT 요청 200(7.77초), local RAG+GPT 요청 200·`answered`(6.71초), 분석 집계 200을 확인했다. 시간은 각 1회 관측이며 지연시간 보장이나 성능 벤치마크가 아니다. RAG 검색 방식은 `bm25+local-cosine-rrf`로 기록됐다.

| 확인 항목 | 목표 또는 작성된 구성 | 최종 확인 결과 |
|---|---|---|
| 공개 접속 URL | 향후 CloudFront HTTPS | **없음 — AWS 서비스 미배포** |
| 배포 버전·확인 시각 | 검증한 산출물 해시와 배포 이력 | **운영 버전 없음** — 로컬 실행 증거와 업로드한 배포 초안을 구분 |
| 서버 경로 | 향후 CloudFront → Nginx → Spring, 별도 Python worker | **현재는 loopback 웹 → Spring → Python**. AWS 초기 설정은 실행하지 못함 |
| EC2 | `c7i-flex.large`, 메모리 4 GiB | 유형 지원 확인. **현재 DriveMate EC2 없음** |
| RDS | PostgreSQL 18.6, `db.t4g.micro`, Single-AZ, 자동 백업 보존 1일 | 실패 배포에서 생성됐으나 **최종 암호화 백업 후 삭제 완료**. 현재 RDS 없음 |
| 문서 저장·검색 | 향후 RDS PostgreSQL pgvector, 원문·벡터 비공개 | **로컬 검색+GPT HTTP 검증 완료 / RDS 적재·SQL 검색 미실행** |
| 모델 요청 | 로그인→차량 입력→공매 결과/유보→근거 설명 | **로컬 실제 ML+GPT 200 / 공개 운영 요청 미실행** |
| 문서 권한 | 사전 승인 계정만 검색. 허용 이메일의 공개 가입 및 삭제 후 일반 재가입 차단 | **로컬 검증 완료** — 초기 토큰 제거·재시작 및 공개 가입 403 확인. AWS에서는 미실행 |
| 주간 사이클 | 향후 EventBridge → SQS → 단일 worker → 비공개 S3 집계 게시 | **AWS 규칙·큐 정리 완료, 운영 사이클 미실행**. 로컬 분석과 worker 코드는 준비됨 |
| CI/CD | GitHub Actions 검사·산출물 생성 및 검토된 버전의 수동 배포 파일. OIDC는 새 공개 대상의 불변 저장소 식별자를 포함한 main 브랜치 subject로 제한 | **코드 업로드·원격 CI 검증 진행 중 / CD 미활성** — `make_drive_mate`의 쓰기·관리 권한 확인. AWS 대상 호스트 없음 |
| 비용 | 사용자 월 20만원 예산 | **실행 중인 EC2·RDS 없음**. 보존한 백업·키·비밀정보·비공개 객체의 저장 비용은 남을 수 있음 |

실패 스택·해당 VPC·빈 작업 큐의 삭제를 확인했다. 최종 백업과 복원용 암호화 키, 별도 foundation의 비공개 S3·애플리케이션 secret은 유지했다. 다음 AWS 배포 때는 최신 소스를 다시 빌드·패키징해야 한다. 자세한 상태는 [AWS 실행 기록](../infra/aws/DEPLOYMENT-STATUS.md)을 따른다.

유료 기능은 **UTC 날짜 기준 서버 전체 요청 20회/일** 한도를 공유한다. 문서 검색 1회는 임베딩 호출을 포함하고 GPT 옵션은 추가 호출을 할 수 있으므로 “OpenAI HTTP 호출이 정확히 20회 이내”와 같은 뜻이 아니다. 실패·미설정 요청도 슬롯을 소비할 수 있다. 이 요청 한도와 예산 알림은 AWS 월 지출의 자동 차단 보장이 아니다.

최종 공개 반영 대상은 사용자가 지정한 [cloud-project-mobility/make_drive_mate](https://github.com/cloud-project-mobility/make_drive_mate)다. 쓰기·관리 권한을 확인했고 코드 업로드와 원격 CI 검증을 진행 중이다. 기존 `FE-test`는 로컬 작업본의 기반으로만 구분한다. 공개 대상에는 소스·테스트·개인정보 없는 기술 문서와 코드 전용 노트북만 반영하고 원본 Office 문서·데이터·모델·RAG 본문/색인·키·계정 설정은 제외한다. 실제 원격 실행 결과가 확인된 뒤 CI 성공으로 기록하며, 현재 AWS 대상이 없어 CD는 활성화하지 않는다.

## 검증·보존 사항

- 최신 Spring `mvn test`와 Surefire 보고서 합계는 **47개 테스트, 실패 0건·오류 0건·건너뜀 0건**이다. 문서 허용 이메일의 공개 가입·삭제 후 재가입 차단 검사 2개, 차량 카탈로그 검사 9개, 명시적 local RAG 설정 검사가 포함된다. 운영 배포 성공 횟수가 아니다.
- RAG의 추출·출처·가림·오류·환경변수 처리 단위 테스트는 9개, CI 배포 어댑터 테스트는 7개다. 이는 실제 RDS 검색 또는 GitHub 원격 Actions 실행 성공 횟수가 아니다.
- 06:55 UTC에 추가 차량 카탈로그·서버 차량 화면을 포함한 현재 통합본을 다시 검사했다. TypeScript·ESLint·**90개 테스트 통과**, 웹 export **986개 모듈 성공**이다. 최신 `dist`는 37개 파일·22,879,233바이트이며 실제 키 문자열 검사 0건이다. 다른 사용자 소스는 수정하지 않았다. 이 추가 화면의 실제 배포 브라우저 확인은 아직 별도 확인 대상이다.
- 초기 Spring 연결 화면 검증에서 TypeScript·ESLint·76개 도메인/경계 검사와 웹 export가 통과했다. 브라우저 34개 시나리오는 33개 통과 후 화면 크기 전환 대기를 수정한 관련 10개 재실행이 모두 통과했다. 이후 추가 변경의 최종 결과는 배포 검증 기록으로 갱신한다.
- 개발 서버에서 비밀 파일의 오류 진단 노출을 발견해 Metro 탐색·직접 URL 차단을 추가했다. 수정 후 개발/배포 번들에서 실제 키 문자열 0건을 확인했다. 과거 개발 서버의 외부 접근자 부재는 로그가 없어 증명하지 않는다.
- 실제 키·허용 계정 이메일·비밀번호·세션·개별 차량 식별자·원본 문서 내용은 이 인수 메모와 공개 발표자료에 넣지 않는다.
- 기존 차량 사진 및 관련 화면 변경은 다른 사용자 작업으로 보존했다. 사진 출처·재사용 조건은 `docs/VEHICLE-PHOTOS.md`의 별도 기록을 따른다.
- 별도 비공개 Colab 노트북은 같은 Drive 파일 ID에 최신 669,524바이트로 갱신했고 재다운로드 바이트 일치까지 확인했다. 현재 Colab 런타임에서 모든 셀을 실행한 것은 아니다. WSL에서 코드 9개 셀·내장 테스트 25개를 순서대로 실행한 검증과 구분한다. 데이터가 내장된 파일과 비공개 공유 링크는 공개 코드 저장소에 포함하지 않는다.
- 원본 `.docx`, `.pptx`, 모델링 노트북은 그대로 보존한다. 수정할 문서의 원고를 만들 프롬프트는 [DOCUMENT-UPDATE-PROMPT.md](DOCUMENT-UPDATE-PROMPT.md)에 있다.

근거 파일: [수집·전처리](ONBID-DATA.md), [모델](ONBID-MODEL.md), [RAG](RAG.md), [반복 분석](CYCLE.md), [프런트 검증](SPRING-FRONTEND-VALIDATION.md). 오래된 문서에 남아 있는 FastAPI·GB·미구현 문구는 그 문서의 작성 당시 상태이며 현재 구현의 근거로 우선하지 않는다.
