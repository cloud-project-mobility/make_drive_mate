# 연동 구현과 운영 확장 지점

기존 기기 저장 앱에 FastAPI·SQLite 백엔드를 추가했다. 로컬 계정·서버 백업과 공급자 연결 경계가 구현되어 있으며, 기본 실행은 실제 API 키가 필요 없는 명시적 `mock` 모드다. [백엔드 실행](../backend/README.md)과 [API·인계 문서](BACKEND.md)를 참고한다. mock 검증 성공을 실제 공급자 연결 성공으로 표시하지 않는다.

도메인 모델과 검증은 `src/domain/`, 서버의 대응 검증은 `backend/app/models.py`에 있다. 서버 응답도 프런트엔드 스키마와 정책을 통과해야 한다. 주행 중 GPS 좌표 이력은 저장하지 않는다. 장소 검색에서 선택한 계획의 출발·도착 좌표와 경로 계산 출처·시각은 저장하고 외부 지도와 서버 백업에도 유지한다. 서버 백업에는 차량·일정·완료 주행·점검 기록이 저장되며, 계정 전환만으로 기기 자료를 자동 교체하지 않는다. 향후 수집 범위가 늘면 보관 기간·삭제·내보내기 계약부터 정한다.

`eas.json`에는 development / preview APK / production 프로필이 있다. EAS 프로젝트 연결, 개발 클라이언트 설치, Apple/Google 서명 자격증명은 별도로 설정해야 한다. 이 작업에서는 앱스토어 배포, EAS 업로드, 배포 서명을 수행하지 않았다.
