# 연동 구현과 운영 확장 지점

기본 백엔드는 `backend-spring/`의 Spring API다. 로컬 개발은 H2, 운영 ECS Fargate는 RDS PostgreSQL을 사용한다. 기존 FastAPI는 이관 참고용으로 남아 있으며 운영 HTTP 서버가 아니다. [Spring 실행 안내](../backend-spring/README.md)와 [공급자 설정](../backend-spring/PROVIDERS.md)을 참고한다. 예시 응답 검증을 실제 공급자 연결 성공으로 표시하지 않는다.

| 영역        | 현재 동작                                                                                                                                                            | 운영 연동 시 필요한 작업                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 계정        | 계정 없는 시작 유지. DriveMate 이메일/비밀번호 계정·세션 만료·로그아웃·계정 삭제 API 사용. 프런트엔드 세션은 메모리에만 보관 | 이메일 소유 확인·메일 기반 비밀번호 복구. Google Calendar 동의는 DriveMate 로그인과 별개 |
| 캘린더      | 서버 예시 일정과 종일·장소 누락 처리. Google OAuth state·PKCE·암호화 토큰 보관·갱신·연결 해제 경계, 반복 일정·페이지 처리·시간대 검증. 일정 선택 후 로컬 계획에 복사 | 실제 OAuth 클라이언트·사용자 동의·Calendar 호출 검증. 원본 변경·취소를 로컬 계획에 지속 반영하는 기능은 별도   |
| 지도·길찾기 | Kakao Local 검색·Mobility 경로 호출, 좌표·거리·시간 검증과 오류 처리. 서버 REST 키 방식이며 개인 계정 OAuth 불필요. 브라우저 지도와 동일 계정 위치 중계 지원 | 운영 키 주입 후 실제 호출과 콘솔 API 권한·할당량 확인. 지도 JavaScript 키·등록 도메인은 서버 REST 키와 구분. 5분마다 자동 경로 갱신은 미구현 |
| 차량 API    | 명시적 합성 차량 상태 조회, 원본 단위·시간대 미확인 관측 시각·수신 시각 구분. 기존 누적거리를 자동 변경하지 않음                                                     | 현대 실차 OAuth·소유 확인·이용 계약·동의와 보관 조건 확인 후 어댑터 구현. 현재 live 요청은 차단                |
| 실시간 위치 | 사용자가 버튼으로 위치 권한 요청. 인증된 같은 계정 세션만 WebSocket 중계, 좌표는 메모리 30초 TTL | 백그라운드 추적·타계정 공유는 미지원. 다중 인스턴스로 확대하기 전 중계 구조 변경 필요 |
| 서버 저장   | 운영 RDS 계정별 스냅샷. 버전 충돌 거부·동일 재전송 중복 저장 방지. 명시적 저장·복원, 주행 중 제한·복원 전 알림 취소 | 자동 병합·오프라인 전송 큐·기기 간 변경 및 삭제 자동 전파는 미구현 |
| 소모품 정책 | 원안의 예시 주기와 점검 이력 도메인 검증 유지                                                                                                                        | 차종·연식·운행 조건별 근거 있는 정책, 사용자 점검 이력 검증, 변경 이력·정책 버전                               |

`DRIVEMATE_PROVIDER_MODE=mock`는 명시적인 예시, `disconnected`는 외부 호출 차단, `live`는 서버 설정을 사용하는 모드다. live로 바꿔도 미설정 서비스를 예시 응답으로 대체하지 않는다. Kakao의 `configured`는 키 설정, 기능별 `live_verified`는 현재 서버 실행 중 실제 응답 검증 성공을 뜻한다. 개인 계정 동의가 없는 API 키 방식을 “계정 연결 전”으로 표시하지 않는다.

도메인 모델과 검증은 `src/domain/`, 서버 대응 검증은 `backend-spring/src/main/java/com/drivemate/api/`에 있다. 서버 응답도 프런트엔드 스키마와 정책을 통과해야 한다. 주행 중 GPS 좌표 이력은 저장하지 않는다. 장소 검색에서 선택한 계획의 출발·도착 좌표와 경로 계산 출처·시각은 저장하고 외부 지도와 서버 백업에도 유지한다. 서버 백업에는 차량·일정·완료 주행·점검 기록이 저장되며, 계정 전환만으로 기기 자료를 자동 교체하지 않는다. 향후 수집 범위가 늘면 보관 기간·삭제·내보내기 계약부터 정한다.

ML·GPT는 공매 낙찰가 모델의 지원 범위·시나리오 검증, 설명 및 문서 근거 검색에 사용한다. 공매 낙찰가를 소비자 중고차 시세로 표시하지 않는다. 새 학습 후보는 평가 후 별도로 승격하며 GPT 요청은 서비스 공용 일일 한도를 사용한다. API 비밀은 서버에서 주입하고 Git·이미지·브라우저 번들에 넣지 않는다. 지도 JavaScript 키는 브라우저 SDK의 공개 식별값이며 등록 도메인으로 사용처를 제한한다.

`eas.json`에는 development / preview APK / production 프로필이 있다. EAS 프로젝트 연결, 개발 클라이언트 설치, Apple/Google 서명 자격증명은 별도로 설정해야 한다. 이 작업에서는 앱스토어 배포, EAS 업로드, 배포 서명을 수행하지 않았다.
