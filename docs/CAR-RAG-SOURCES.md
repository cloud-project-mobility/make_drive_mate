# 차량 상담 근거 자료

검토일: 2026-11-05. 이 문서는 자료 선정과 적용 범위 기록이다. 실제 임베딩·RDS 적재·운영 배포 성공을 뜻하지 않는다.

차량 상담은 기존 프로젝트 문서 검색과 별도의 `public_vehicle` 컬렉션을 사용한다. 기존 6개 문서/83개 청크에는 계획서·중간보고서·발표자료와 내부 모델 평가가 섞여 있으므로 일반 차량 상담의 공용 근거로 열지 않는다.

제조사의 공식 목록 응답으로 차종 코드·연식·한국어·한국 시장(`A99`)·문서 식별자를 함께 확인했다. 목록 경로는 각 공식 도메인의 `/api/v2/{hmc|kia}/model/owners-manuals`이며 응답 사본과 SHA-256은 로컬 출처 manifest에 보존한다. 등록·수정일은 공식 사이트에 표시된 문서 날짜이며 차량의 생산일이나 최신 리콜 검증일이 아니다.

모델 연식만으로 개별 차량의 부분변경 여부·트림·선택 장비까지 확정하지 않는다. 카탈로그의 아이오닉 5 사진도 실제 국내 차량의 사양을 증명하지 않는다. 이번 자료는 동일 모델/연식의 공통 서술형 관리 원칙만 담으며, 장비별 조작이나 엔진별 교환 수치·타이어 제원은 원문과 실제 차량을 추가 확인해야 한다. 다른 연식·연료에 임의로 확장하지 않는다.

## 본문 및 출처 계약

- 제조사 설명서 3종에서 주제별 요약 12개(문서 12개/청크 12개)를 직접 작성했다. 제조사 문장을 그대로 인용한 원문 복제본이 아니므로 화면 명칭은 **근거 요약**이다. `source_kind=official_manual_summary`, `content_kind=narrative`를 문서와 청크 모두에 기록한다.
- `audience=public_vehicle`, `purpose=public_vehicle`, `schema_version=vehicle-rag-v1`을 강제한다. 문서와 청크의 출처 URL·적용 범위가 일치해야 한다. 허용 출처 호스트는 `ownersmanual.hyundai.com`, `ownersmanual.kia.com` 두 곳이다.
- `applicability`는 `scope`, `make`, `model`, `year_from`, `year_to`, `fuel_types`로 구성한다. 이번 12개는 모두 `model_specific`이며 상·하한 연식이 같다. 연료 목록을 비워 전체 연료에 적용하는 자료는 없다. `ICE`는 연료명이 아니므로 휘발유로 자동 간주하지 않는다.
- 아반떼 PDF는 **물리 페이지** 1, 374, 375, 396을 사용한다. 인쇄면은 각각 앞표지 안내, 9-6, 9-7, 9-28이다. 선택 페이지를 실제 렌더링하여 절과 페이지를 확인했다. HTML 자료는 페이지 번호를 만들어내지 않고 `page=null` 및 실제 절 URL을 쓴다.
- 본문에는 차량번호·차대번호·소유자·개인 연락처·주소·키를 넣지 않았다. 외부 문서의 지시문을 시스템 지시로 취급하지 않는다. 원본과 검토용 추출문은 Git에 넣지 않는다.

로컬 준비 경로: `backend/data/vehicle-rag/reviewed-20261105-v1/corpus.json`, `source_manifest.json`. 해당 폴더는 기존 `backend/data/` 제외 규칙 아래 있다. 이 단계의 `corpus.json`에는 벡터가 없으며 별도 승인된 임베딩/적재 단계에서 생성한다. 자료 해시는 `2f9337c8eb068a11c701d81bda8b31fa2bc1694861dc693c31a573e6a9fe702f`다.

## 이번 자료로 답할 수 있는 질문

선택한 차량·연식·연료가 맞으면 정체와 단거리 운전에서 정비 기준을 어떻게 읽는지, 주행 전 무엇을 살필지, 오일 교환과 오일량 점검을 왜 구분하는지, 냉간 공기압 확인이 왜 필요한지, 전기차의 주행거리가 환경에 따라 달라지는 이유 등을 해당 요약과 공식 원문 링크로 설명할 수 있다.

정비 이력 없이 특정 부품이 고장 났다고 진단하거나 실제 교체일·비용·배터리 건강도·보증 적용·최신 리콜을 확정할 수 없다. 정량 주기표와 압력값을 이번 본문에 넣지 않았으므로 구체적인 교환 거리·기간이나 공기압 숫자를 생성하면 안 된다. 미래 시세·최적 매도일·거래량도 이 자료의 답변 범위가 아니다. 가격은 기존 서버 ML 계산 근거를 별도로 사용한다.

## 검증 및 갱신

자료 검증은 공식 출처 응답, 제한된 본문 검토, PDF 선택 페이지 시각 확인, 해시·스키마·민감정보 패턴 검사다. 검색 정확도와 실제 운영 답변 품질은 별도 retrieval 평가 및 배포 검증으로 보고해야 한다. 이 준비만으로 RAG 정확도나 운영 연결을 보장하지 않는다.

문서가 바뀌면 새 파일·해시·적용 범위로 별도 버전을 만들고 기존 컬렉션을 바로 덮어쓰지 않는다. 새로운 차종이나 연식을 지원하려면 공식 원문을 추가 확인한 뒤 명시적으로 범위를 늘린다.
