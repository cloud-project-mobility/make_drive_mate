## 문서 검색과 운영 전환 주의

현재 보존된 RAG 인덱스는 6개 문서·83개 청크이며, 이 중 `code_verified` 1문서·4청크가 **기존 모델 평가**를 담고 있다. 해당 스냅샷은 기존 metrics와 일치하고 후보와 일치하지 않는다. 문서 생성 코드도 현재 기존 metrics 경로를 읽는다.

후보를 채택한다면 기존 원본을 덮어쓰지 않고 새 평가 경로·본문·해시를 가진 새 불변 인덱스를 만들어야 한다. 변경하지 않은 79개 청크의 벡터는 재사용하고, 바뀐 평가 청크만 임베딩하는 방식이 최소 갱신이다. 이는 아직 구현·실행한 갱신이 아니라 필요한 후속 절차이다. 검색 회귀 평가 후 DB 적재 및 활성 포인터 전환까지 맞춰야 모델 응답과 문서 답변이 충돌하지 않는다.

후보 폴더의 `coverage_audit.json`, `integrity_audit.json`, `model/metrics.json`, `summary.json`과 보고서는 로컬 검증 산출물이다. 원시 데이터, 사건 ID, 모델 번들 및 실제 환경 파일은 공개 Git 저장소에 넣지 않는다.
