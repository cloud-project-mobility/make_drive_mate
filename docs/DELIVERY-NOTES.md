# DriveMate 인수 메모

작성 기준: **2026-11-04, ECS Fargate와 최종 공개 HTTPS/WSS 검증 완료**. 서비스는 [DriveMate 웹](https://d2a3l7qimjk3ir.cloudfront.net)에서 실행되며 기존 RDS를 재사용한다. 첫 데이터 사이클·API 집계 갱신과 주간 요청·시간 단위 worker 예약 활성화를 확인했다. 이전 EC2·CloudFront·VPC origin 정리와 추가 RAG 10건 평가도 완료했다. 원본 Word·PowerPoint 파일은 이번 작업에서 수정하지 않았다.

## 전달된 기능

사용자가 차량 조건을 입력하면 온비드 공매 낙찰 자료로 학습한 모델이 현재 조건의 참고 가격을 계산한다. 차령·예상 주행거리·입력 유지비를 바꿔 보유 조건을 비교하고, 데이터가 부족하면 가격 제시를 유보한다. 이는 소비자 중고차 시세나 확정 매입견적, 실제 미래 시장가격 예측이 아니다.

화면은 실제 공매 모델, 데이터 분석 집계, 기존 오프라인 합성 계산, 프로젝트 문서 근거 검색을 구분한다. GPT는 검증된 가격·사례 설명 또는 문서 출처를 선택하며 가격 자체를 생성하지 않는다.

## 숫자를 보고하는 방법

| 가격 모델 평가                        |  표본 |        MAE | 함께 표시할 정보                                    |

| 전체 최종 시험                        | 341건 | 236.15만원 | 모든 시험 자료에 대한 결과                          |

정제 2,197행 중 시간 경계를 넘는 53개 차량 그룹·122행을 제외한 분할은 훈련 839, 검증 559, 구간 보정 336, 시험 341행이다. 차종·세대·사고·정비·트림 정보의 한계와 공매 표본 편향을 함께 설명한다. 조건부 MAE를 전체 정확도나 소비자 매입가격 정확도로 바꾸어 쓰지 않는다.

가격 유보는 미학습 모델·제조사 조합 또는 핵심 수치의 훈련 범위 이탈에 적용한다. 같은 모델의 훈련 표본이 10건 미만인 경우는 경고이며, 그 조건 하나만으로 자동 유보하지 않는다. 범위 안에 있다는 사실이 모든 차량 조합의 근거가 충분하다는 뜻은 아니다.

이전 로컬 문서 검색 점검은 개발자가 작성한 작은 확인용 질문 10개에서 Recall@1 0.70, Recall@3 0.90, Recall@6 0.90, MRR@6 0.7667이었다. 독립적인 일반 성능 시험이 아니다. 문서 밖 질문 3개는 당시 실제 LLM 선택에서 3/3 보류했지만, 단순 유사도 게이트만으로는 3개 모두 통과했다. 아래의 최종 ECS 10건 평가와 다른 시험이며 “환각 0%”, “정확도 100%”, “문서 밖 질문 완벽 차단”으로 쓰지 않는다.

최종 [ECS RAG 평가](RAG-EVALUATION-20261104.md)는 근거 질문 8개·문서 밖 질문 2개를 실행했다. HTTP 200 10건, GPT 답변 8건·LLM 미호출 유보 2건이며 사전 자동 판정은 **8/10**이었다. 추가 원문 대조에서는 답변 8건의 관련성·충분성과 유보 2건이 적합했다. Q04/Q07의 자동 불일치는 유효한 다른 출처를 허용하지 않은 평가 기준의 한계로 설명하며 점수를 사후 수정하지 않는다. 질문 목록·사용량·지연 집계만 공개하고 문서 발췌와 답변 본문은 공개하지 않는다.

## 현재 실행과 AWS 상태

핵심 제품 작업 중 실제 ML 결과와 매도 목표·최소 보유기간을 함께 적용하는 추천 흐름, 실제 미래 시장가격 검증, 보유비용 근거 확보는 남아 있다. 기존 오프라인 합성 계산을 실제 ML 추천 통합으로 보고하지 않는다. 신규 차량 관련 RAG 자료는 아직 기존 6문서·83청크 서비스 색인으로 확대 반영하지 않았으며, 팀원 모바일 검증과 원본 PoC·중간보고서·PPT 수정도 별도 남은 작업이다.

`backend/data/local-run/verification.json`에서 로그인 200, 예약 이메일 일반 가입 403(`email_reserved`), 실제 ML+GPT 요청 200(7.77초), local RAG+GPT 요청 200·`answered`(6.71초), 분석 집계 200을 확인했다. 시간은 각 1회 관측이며 지연시간 보장이나 성능 벤치마크가 아니다. RAG 검색 방식은 `bm25+local-cosine-rrf`로 기록됐다.

이전 실패 스택의 정리와 최종 암호화 백업 보존은 과거 이력이다. 이후 ECS 전환 검증을 마치고 임시 EC2·기존 CloudFront·VPC origin을 삭제했다. 현재 서비스는 ECS와 보존한 RDS에서 실행된다. 같은 RDS endpoint의 available·암호화·삭제 보호·백업 1일 유지를 확인했다. 자세한 상태는 [AWS 실행 기록](../infra/aws/DEPLOYMENT-STATUS.md)을 따른다.

첫 ECS cycle task `f60172775bd643f8bf0e8d6221328487`의 실행 `20261104T111517Z-6ac82deb`는 `onbid-api-v1` 형식으로 2025-11-04~2026-11-03 개찰 자료를 13회 호출했다. 원본 5,268행, 승용 범주 2,284행, 정제 2,187행, 전체 제외 3,081행, 반복 그룹 154개이며 예약 중인 API 호출은 0건이다. S3 최신 집계와 완료 표식의 실행 ID가 일치하고 AES256 암호화를 확인했다. **현재 서비스 학습본 2,197행, 역사 내보내기 후보 14,867행, 새 API cycle 2,187행은 서로 다른 산출물**이며 신규 결과는 `production_promoted=false`다.

최종 공개 API는 같은 실행 ID·2,187행과 `complete_scope=api_collection`, `upstream_collection_verified=true`를 보고했다. 주간 메시지는 월요일 02:00 KST에 생성하고 worker는 매시 05분에 큐 1건을 처리하도록 각각 활성화했다. 빈 큐이면 종료하므로 매시간 새 수집을 뜻하지 않으며 첫 정기 실행의 성공은 이후 확인해야 한다.

최종 HTTPS/WSS smoke는 1회 관측 15.249초에 통과했다. health·로그인 200, 지원 차량 ML 템플릿, pgvector 출처 6개, 다른 계정 RAG 403, 예약 이메일 가입 403, 같은 계정 합성 위치·중지와 다른 계정 0건을 확인했다. 임시 계정 2개를 삭제하고 해당 소유자 로그인 세션을 폐기했다. RAG는 질문 임베딩을 호출했으며 LLM 생성은 0회였다. 실제 GPS·모바일 검증이나 응답시간 보장이 아니다.

초기 공개 경로의 403은 ALB의 전달 포트 80과 HTTPS Origin 불일치가 원인이었다. Nginx의 API·WS 경로에서 전달 포트를 443으로 고정하고 `Forwarded`를 제거했다. 기존 이미지 실패를 재현한 뒤 새 이미지에서 동일 출처 POST/WS와 타 출처 403을 함께 확인했다. 새 공개 도메인의 카카오 JavaScript SDK 허용 설정도 저장·검증했지만 실제 차량·기기 GPS 검증을 대신하지 않는다.

일반 API task는 DB master secret·초기 소유자 비밀번호·bootstrap token을 받지 않으며 스키마 자동 초기화도 끈다. 다만 기존 bootstrap의 `drivemate_app` 역할은 현재 schema/table owner이므로 DB 권한을 DML 전용으로 낮춘 상태는 아니다. 위치 중계는 메모리 기반 단일 replica이며 task 교체 시 사용자가 다시 연결해야 한다.

유료 기능은 **UTC 날짜 기준 서버 전체 요청 20회/일** 한도를 공유한다. 문서 검색 1회는 임베딩 호출을 포함하고 GPT 옵션은 추가 호출을 할 수 있으므로 “OpenAI HTTP 호출이 정확히 20회 이내”와 같은 뜻이 아니다. 실패·미설정 요청도 슬롯을 소비할 수 있다. 이 요청 한도와 예산 알림은 AWS 월 지출의 자동 차단 보장이 아니다.

공개 저장소는 사용자가 지정한 [cloud-project-mobility/make_drive_mate](https://github.com/cloud-project-mobility/make_drive_mate)다. 최초 통합 업로드는 [`8b8eea7484ebe8cf8f2dde10ab0f6737a1d5aa21`](https://github.com/cloud-project-mobility/make_drive_mate/commit/8b8eea7484ebe8cf8f2dde10ab0f6737a1d5aa21)이며 이후 변경과 CI 결과는 [Actions 기록](https://github.com/cloud-project-mobility/make_drive_mate/actions)을 따른다. 기존 `FE-test`는 로컬 작업본의 기반으로 구분한다. 소스·테스트·개인정보 없는 기술 문서와 코드 전용 노트북만 공개하며 원본 Office 문서·데이터·모델·RAG 본문/색인·키·계정 설정은 제외한다. CI 성공과 ECS 배포 완료·CD 활성화는 서로 다른 상태다.

- 기록된 최신 로컬 Spring 검사는 **57개, 실패 0건**이다. 실제 WebSocket·Origin·메시지 순서 검사를 포함하며 운영 배포 성공 횟수가 아니다.
